# Глоссарий

| Термин | Значение |
| --- | --- |
| Project | Git-native React-проект, открываемый обычной IDE |
| Site | публикуемая единица проекта; installation может быть single или multiple-site |
| Component / Primitive | готовая сущность UI / её низкоуровневый reusable building block |
| Content | редактируемые значения Component Schema; locale — его вариант |
| Asset | выбранный файл и metadata, а не ссылка, зашитая в JSX |
| Route | frontend React route или Gateway network rule; тип всегда указан явно |
| Snapshot | согласованная deployable ссылка на Git revision и metadata |
| Build | immutable artifact, собранный из Snapshot |
| Deployment | связь Environment, Build и фактически активного состояния |
| Plugin | изолированный capability-процесс Gateway |
