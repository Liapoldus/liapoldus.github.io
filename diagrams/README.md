# Исходники схем

`*.mmd` — единственные редактируемые исходники диаграмм. SVG в
`public/diagrams/` генерируются из них и подключаются документацией как
статические assets, поэтому Mermaid не попадает в runtime bundle VitePress.

VitePress сам генерирует SVG перед `npm run dev` и `npm run build`. В dev-режиме
изменение `.mmd` пересобирает только затронутую схему и перезагружает страницу.
Отдельную команду запускать не нужно.

Для проверки документации достаточно:

```bash
npm run build
```
