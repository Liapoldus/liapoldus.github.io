# Changelog

Публичных релизов gateway и плагинов пока нет: проект находится в стадии
разработки, и каждый крупный этап обязан оставаться собираемым (`go build`,
`go vet`, `go test`). Разрешены breaking changes и прямые переименования,
поэтому ниже — вехи развития, а не история стабильных версий.

## Вехи

| Дата | Компонент | Что произошло |
| --- | --- | --- |
| 2026-09 | docs | Документационный сайт: главная на корне, разделы `/gateway/`, `/plugins/`, практические примеры, changelog, локальный поиск |
| 2026-09 | docs | Переезд хостинга на `liapoldus.github.io`, CI на GitHub Pages (node24 actions) |

План работ и критерии готовности этапов живут в `TODO.md` и `task/`
репозитория; контракт протокола зафиксирован в
[`contract.md`](/gateway/architecture/contract).

## Как читать

- **Обозначения версий** вводятся, когда появится первый публичный релиз.
  До этого изменения фиксируются веткой/коммитом и датой.
