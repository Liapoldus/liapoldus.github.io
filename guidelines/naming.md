# Именование

Имена отражают предметную сущность и одинаковы в code, schemas, API и docs.
`Snapshot`, `Build`, `Deployment` и Git commit — разные термины. Route всегда
уточняется как React route или Gateway route.

Public config/API keys — строчные stable identifiers, объявленные в versioned
schema; неописанная строка не становится контрактом. Внутренние имена не
протекают в public API.
