# Code Guidelines

Эти правила действуют для всех продуктов Liapoldus. Продуктовые правила не
дублируются здесь: для Core они находятся в его архитектуре, для plugins —
в принадлежащих им contracts.

## Базовые требования

- публичный контракт versioned, typed и документирован рядом с исходником;
- зависимости идут к меньшим стабильным абстракциям, а не между продуктами;
- secrets, персональные данные и raw credentials не логируются;
- любое изменяемое поведение проверяется unit и integration тестами отдельно
  от production-кода;
- документация описывает ownership и failure mode, а не только happy path.
