# CLI

Офлайн-доставка и управление: все подкоманды — операции над диском
(registry + конфиги), работающий gateway и БД не нужны. Единственный
долгоживущий процесс — `serve`.

```text
gateway <подкоманда> [флаги]
```

## Подкоманды

| Группа | Подкоманды | Назначение |
| --- | --- | --- |
| Запуск | [`serve`](serve) | долгоживущий процесс: публичный рантайм + management |
| Версии сайта | [`versions`, `current`, `prev`, `rollback`](versions) | просмотр версий и откат в registry |
| Диагностика | [`config`, `routes`, `status`, `health`](inspect) | конфиг/маршруты сайта и состояние registry |
| Service accounts | [`accounts`](accounts) | выпуск, ротация и отзыв API-ключей |
| Справка | `help` | список подкоманд |

## Глобальные флаги

| Флаг | Назначение |
| --- | --- |
| `--config PATH` | путь к конфигу процесса (нужен подкомандам, работающим с `gateway.yaml`) |
| `--help` | справка |
