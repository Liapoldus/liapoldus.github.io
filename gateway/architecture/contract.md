# Контракт plugin protocol

Эта ссылка сохранена для совместимости. Единственный канонический контракт
между Gateway и плагином — [Plugin protocol](/gateway/architecture/protocol):
transport, фреймы, методы, потоки, отмена, лимиты и ошибки описаны там.

Для практической реализации используйте [гайд создания плагина](/gateway/architecture/guide),
а для декларации instance — раздел [«Плагины»](/plugins/).
