# Liapoldus

Liapoldus — файловая платформа для предсказуемой публикации публичных сайтов.
Её ядро — Gateway: он принимает трафик, отдаёт проверенную версию сайта и по
явному правилу передаёт отдельные задачи внешним плагинам.

## Какую проблему решаем

Команде нужен короткий и проверяемый путь от собранного артефакта до домена —
без обязательной панели управления, базы данных Gateway и набора несогласованных
proxy-конфигураций. Оператор всегда должен видеть активную версию, результат
изменения и безопасный путь отката.

## Продуктовые границы

**В продукт входят:** публикация статических сайтов, маршрутизация к
upstream-сервисам, TLS, версии и откат, наблюдаемость и изолированные плагины
для серверных возможностей сайта.

**Не входят в ядро:** CMS, редактор контента, пользовательские аккаунты сайта,
CI/CD, выдача сертификатов и централизованная облачная control plane. Их можно
подключать снаружи через файлы, API и стандартный HTTP.

## Принципы продукта

- **Файлы — источник правды.** Конфигурация и релизы переносимы,
  просматриваются в Git и восстанавливаются без скрытого состояния.
- **Безопасное действие важнее удобной команды.** Валидация происходит до
  публикации; опасные действия показывают цель, последствия и путь отката.
- **Простой путь — короткий.** Первый статический сайт не требует знания
  плагинов, API управления или внутреннего протокола.
- **Расширение без проникновения в ядро.** Предметная логика живёт в плагинах;
  Gateway остаётся владельцем трафика, маршрутизации, политик и супервизии.
