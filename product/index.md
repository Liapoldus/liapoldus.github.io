# Liapoldus

Liapoldus — самостоятельная платформа публикации публичных сайтов. Её ядро —
gateway, который принимает HTTP(S)-трафик, отдаёт версии сайтов из registry и,
при необходимости, передаёт отдельные маршруты подключаемым возможностям.

## Какую проблему решаем

Команде сайта нужен предсказуемый путь от собранного артефакта до публичного
домена — без обязательной панели управления, собственной базы данных gateway
и набора несогласованных прокси-конфигураций. Оператор должен понимать, какая
версия опубликована, как её проверить и как безопасно откатить.

## Продуктовые границы

**В продукт входят:** публикация статических сайтов, маршрутизация к
upstream-сервисам, TLS, версии и откат, наблюдаемость, а также изолированные
плагины для серверных возможностей сайта.

**Не входят в ядро:** CMS, редактор контента, пользовательские аккаунты сайта,
CI/CD, выдача сертификатов и централизованная облачная control plane. Их можно
подключать снаружи через файлы, API и стандартный HTTP.

## Принципы продукта

- **Файлы — источник правды.** Конфигурация и опубликованные артефакты должны
  быть переносимы, просматриваться в Git и восстанавливаться без скрытого
  состояния.
- **Безопасное действие важнее удобной команды.** Валидация происходит до
  публикации; опасные действия показывают цель, последствия и путь отката.
- **Простой путь — короткий.** Первый статический сайт не требует знания
  плагинов, API управления или внутреннего протокола.
- **Расширение без проникновения в ядро.** Предметная логика живёт в плагинах,
  а gateway остаётся транспортом, маршрутизатором и супервизором.
