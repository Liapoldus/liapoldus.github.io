# Обзор plugin-ов

Все plugins используют Plugin SDK для Core-facing lifecycle и универсальных
`GET /healthz` и `GET /metrics`; `pluginprotocol` предназначен только для
прямого plugin-to-plugin транспорта. Текущая область работ и список оставшихся
acceptance gates поддерживаются на канонической странице
[«Плагины Liapoldus»](/plugins/), без дублирования таблицы статусов.
